# IT Helpdesk — Frontend

React + Vite + TypeScript single-page application.

```powershell
npm install     # first run only
npm run dev     # http://localhost:5173
npm run build   # typecheck and produce dist/
npm run lint
```

Requires the Laravel API to be running at the URL set in `VITE_API_BASE_URL` (see `.env.example`).

Full setup instructions, architecture notes and development standards are in the
[project README](../README.md).
