# How to Use the IT Helpdesk (for Staff)

**Open the app:** `http://localhost:5173/`  
On the office network: `http://192.168.20.3:5173/`

This guide is for **normal users** (employees) who need help from IT.

---

## 1. Sign in

1. Open the link above in your browser.
2. Enter your **username** and **password**.
3. Click **Sign in**.

**No account yet?**

1. Click **Register**.
2. Enter your name, branch, employee ID, EPF number, username and password.
3. Submit.
4. Wait until IT **approves** your account, then sign in.

If you forget your password, ask IT to reset it.

---

## 2. What you can do

After login, use the left menu:

| Menu | Use it to… |
| ---- | ---------- |
| **Dashboard** | See your recent tickets and quick shortcuts |
| **Create Ticket** | Ask IT for help |
| **My Tickets** | Check progress on your requests |
| **Knowledge Base** | Read simple how-to articles |
| **Profile** | View your account details |

Also use the **bell icon** (top) for notifications.

---

## 3. Create a ticket (raise a request)

1. Click **Create Ticket**.
2. Fill in:

   - **Subject** — short title (example: “Printer not working”)  
   - **Category** — Hardware, Software, Network, Printer, etc.  
   - **Priority** — how urgent it is for your work  
   - **Description** — what is wrong, when it started, what you tried  
   - **Branch** — where the problem is  
   - **Location / desk** — desk or floor number (optional)  
   - **Preferred contact** — phone / email / Teams (optional)  
   - **Attachments** — screenshot or photo (optional)

3. If the form asks for **issue type** / **item type** (for hardware or printer requests), fill those too.
4. Click **Submit ticket**.
5. Save the **ticket number** shown (example: `IT-2026-000123`).

### Good ticket tips

- Write clearly.  
- Add a screenshot if there is an error message.  
- Choose the correct branch.  
- Do **not** write passwords in the ticket.

---

## 4. Check your tickets

1. Open **My Tickets**.
2. Click any ticket to see:
   - Current status  
   - Messages from IT  
   - Files / attachments  
3. To reply: type a message and send.  
4. To add more files: upload an attachment on the ticket.

---

## 5. When IT says it is fixed

When your ticket is **Resolved**, you must respond:

1. Open the ticket (or the popup/notification).
2. Check that the problem is really fixed.
3. Choose one:

   - **Confirm** — yes, it works → ticket closes  
   - **Reject** — still broken → IT will continue working  

Please do this soon so your ticket does not stay waiting.

---

## 6. Ticket status meanings

| Status | Meaning |
| ------ | ------- |
| **New** | Just submitted |
| **Assigned** | Given to an IT person |
| **In Progress** | IT is working on it |
| **On Hold** | Temporarily paused |
| **Awaiting User** | IT is waiting for your reply |
| **Resolved** | IT thinks it is fixed — please Confirm or Reject |
| **Closed** | Finished |
| **Cancelled** | Cancelled |

---

## 7. Common problems

| Problem | What to do |
| ------- | ---------- |
| Cannot sign in | Check username/password, or ask IT if your account is approved |
| Registered but cannot log in | Wait for IT approval |
| Cannot download a file | Refresh the page and try again |
| Need urgent help | Create a ticket with higher priority, or call IT |

---

## Quick steps (summary)

1. **Sign in**  
2. **Create Ticket** → fill details → **Submit**  
3. Check progress in **My Tickets**  
4. Reply if IT asks questions  
5. When resolved → **Confirm** or **Reject**

That’s all you need for day-to-day use.
